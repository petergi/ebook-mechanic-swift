## Project Understanding

I understand that this directory contains the `EbookMechanicApp` package, which is a native macOS application with a SwiftUI interface for the EbookMechanic project. This app provides a graphical user interface to the functionality of the `EbookMechanicCore` library.

Key features of this app include:

*   A beautiful and user-friendly SwiftUI interface.
*   Real-time progress updates during scanning and repair operations.
*   A native directory picker for selecting ebook libraries.
*   Toggle controls for configuring scan options.

This package depends on `EbookMechanicCore` for its underlying functionality and is built using modern SwiftUI and Swift Concurrency practices.
