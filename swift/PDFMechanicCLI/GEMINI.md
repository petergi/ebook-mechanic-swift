# Gemini's Role in PDFMechanicCLI

This file outlines the role of the Gemini AI assistant in the PDFMechanicCLI package.

## Project Understanding

I understand that this directory contains the `PDFMechanicCLI` package, which is a specialized command-line tool for validating and repairing PDF and AZW4 ebook files. This CLI is a lightweight and focused alternative to the full-featured `EbookMechanicCLI`, designed specifically for PDF-related tasks.

Key features of this CLI include:

*   Validation of PDF-specific features, such as the header and EOF markers.
*   Advanced repair capabilities for a variety of PDF header corruption issues.
*   A simplified command-line interface with options tailored for PDF files.

This package depends on `EbookMechanicCore` for its underlying functionality.
